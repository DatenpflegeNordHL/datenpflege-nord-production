## Cannibalization gate

One cluster gets one intentional primary owner. A supporting section, fragment or contextual internal link does not become a second owner. Before any new URL, prove distinct intent/SERP, truthful business fit, unique value and a non-competing ownership boundary.

## Default HOLD

Do not create without new first-party/SERP evidence:

- Kiel Web;
- Hamburg AI;
- Schleswig-Holstein regional clones;
- city-specific n8n pages;
- standalone API page;
- standalone n8n authority page;
- Individualsoftware examples page.

## REJECT

- generic Systemintegration acquisition page;
- city/keyword-swapped filler or doorway pages;
- any page whose only justification is search volume.

Prefer `EXPAND` on the existing owner when the user task can be served there without confusing ownership.
