# Runbook: authority research

1. Read `../BUSINESS-TRUTH.md` and `../AUTHORITY-RULES.md`.
2. Verify the target exists using its first-party site/API.
3. Classify `SAFE NOW`, `WAIT FOR ENTITY`, `HUMAN ACTION REQUIRED`, `DEFERRED` or `REJECTED`.
4. Record exact entity/URL, prerequisites, owner, verification method and completion evidence in `../AUTHORITY-EXECUTION-QUEUE.md`.
5. Prefer real technical contributions/projects over directory volume.
6. Never claim membership, customer permission, review count, traffic, adoption or link placement before it is independently visible.

Do not create a backlink solely to complete a queue row.
