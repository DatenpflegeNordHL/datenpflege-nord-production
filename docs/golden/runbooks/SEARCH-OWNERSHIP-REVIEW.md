# Runbook: search ownership review

1. Confirm business truth and service area.
2. Use first-party GSC evidence when available; otherwise preserve current owners.
3. Classify the query task and inspect actual SERP intent before proposing a URL.
4. Check `../SEARCH-OWNERSHIP.md` and the detailed ownership map for overlap.
5. Require distinct intent, unique value and a clean primary-owner boundary before `BUILD`.
6. Prefer `EXPAND` when the existing owner can satisfy the task.
7. Update ownership documentation and tests together when a primary owner legitimately changes.

Search volume alone never grants BUILD permission.
