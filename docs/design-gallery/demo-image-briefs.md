# Showcase demo image briefs

The current demo imagery is self-authored local SVG art-direction material. It contains no legacy-template media, brands, trackers, hotlinks or external image requests. The SVGs are deliberately replaceable through the existing `<img>` slots without changing page layout.

For a later photographic pass, use only generated or explicitly licensed local assets and retain the current dimensions/aspect ratios:

- `nordic-editorial`: bright coastal architecture hero; pale timber/stone/daylight detail.
- `human-service`: real craftsperson at work in a bright workshop; hands/tool/material detail.
- `regional-trust`: high-quality regional residential exterior; bright lived-in interior with large windows.
- `product-led`: product UI/device visualization; focused mobile workflow/detail view.
- `quiet-luxury`: restrained architecture at dusk; stone/oak/linen material study.
- `growth-story`: people/process/print editorial studio image; tactile print/color/sketch detail.

When raster images replace these SVGs, prefer AVIF/WebP, preserve explicit width/height, keep the hero eager/high-priority, and keep below-fold media lazy/async.
