# REGIONAL SERP GATES — DatenpflegeNord

Status: Golden Website Build 2.0 regional acquisition evidence
Last checked: 2026-09-13
Scope: Lübeck, Kiel, Hamburg, Schleswig-Holstein

This appendix records city-targeted SERP reality checks separately from raw keyword volume. A location/service URL is not approved merely because a keyword tool reports demand.

## Gate model

A regional landing page may move from HOLD to BUILD only when all applicable gates pass:

1. **Business truth** — DatenpflegeNord genuinely serves the market and can fulfill the promised service.
2. **Demand** — measurable commercial demand or strong strategic value exists.
3. **SERP commerciality** — the result set is meaningfully procurement/service-oriented, not mostly jobs, study, definitions or unrelated intent.
4. **SERP distinction** — the target deserves its own ownership rather than being a lexical variant of an existing URL.
5. **Unique local value** — the proposed page can contain genuinely useful local/service detail beyond replacing the city name.
6. **Proof/entity support** — local/regional claims, references, process and external entity signals are verifiable.
7. **Cannibalization safety** — the new URL does not compete with an existing owner for substantially the same query set.

Statuses: PASS, PARTIAL, HOLD, BLOCK.

## 6. GEO implications

Regional GEO work must increase the probability that the business and its pages can be cited as useful sources. Current evidence favors:
- original checklists/tools/comparison content;
- verifiable project/process evidence;
- explicit but truthful service geography;
- consistent brand/legal/domain entity data;
- legitimate regional/industry citations and reviews;
- pages that directly answer buyer decisions rather than generic AI-written location filler.

A local keyword in a title is not GEO strategy.
